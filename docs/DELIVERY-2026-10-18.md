# Devcon Follow — engineering delivery, 18 October 2026

This bundle is the existing source with targeted correctness and security patches. It is **not** a verified production launch. No accounts or location samples are fabricated.

## Code changes actually made

1. **Profile editor**: restored missing React `avatar`, `setAvatar` and `photo` binding; accepts JPEG/PNG/WebP (5 MB input maximum), shrinks to maximum 180 pixels and compresses to a small JPEG under the API's avatar size limit; shows an error when unsupported.
2. **Off-site follows**: existing connections load independently from live on-site directory, and saved discoverable profiles are accessible to verified account holders after leaving the event. Creating new follows remains subject to on-site checks.
3. **Immediate stop**: disabling discovery/profile, leaving the venue, or stopping sharing revokes pending/approved location requests, discards latest coordinates and deletes the user's rotating BLE tokens.
4. **Account deletion**: signed-in users without a verified ticket can erase stored account-related data as well. Ephemeral peer tokens are deleted with the account.
5. **Database constraints**: API bootstrap now calls `ensureIndexes()` before opening its public HTTP listener, refusing incompatible populated indexes rather than silently changing live data.
6. **Sensitive responses**: API responses emit `Cache-Control: no-store, private` and the service worker refuses OAuth callback query strings, authenticated API requests, health endpoints and other user-specific URLs.
7. **JWT validation**: only RS256, PS256 or ES256 signed OIDC JWTs are accepted. Production server rejects non-HTTPS OIDC issuer or JWKS URLs.
8. **Abuse control**: repeat follow requests do not trigger repeat notifications; reports target a real verified attendee and are capped at five per reporter per day.
9. **Tests**: added organizer ticket-binding tests (QR alone cannot verify; identity mismatch rejected; valid identity only persists HMAC) and PWA cache tests (including OAuth code URL).
